# Settings Section

User preferences, API configuration, and account management.

## Components

- `SettingsModal.tsx` — Main settings container
- `SettingsTabs.tsx` — Tab navigation
- `AccountSettings.tsx` — Profile and account
- `APIKeySettings.tsx` — API key management
- `APIKeyInput.tsx` — Individual key field
- `AppearanceSettings.tsx` — Theme and display
- `ShortcutsSettings.tsx` — Keyboard customization
- `BillingSettings.tsx` — Subscription management

## Sample Data

- `data.json` — Default settings and plans
- `types.ts` — TypeScript interfaces
