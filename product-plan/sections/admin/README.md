# Admin Dashboard Section

Administrative controls for platform management (admin users only).

## Components

- `AdminLayout.tsx` — Admin page wrapper
- `AdminNav.tsx` — Admin sidebar navigation
- `MetricCard.tsx` — Key stat display
- `UsageChart.tsx` — Time-series visualization
- `UserTable.tsx` — User management list
- `UserDetailDrawer.tsx` — User details panel
- `AgentCard.tsx` — AI agent status
- `LogViewer.tsx` — Real-time log stream
- `FinanceChart.tsx` — Revenue/cost charts
