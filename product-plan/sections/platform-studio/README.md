# Platform Studio Section

AI-powered design studio for each social platform.

## Components

- `StudioPage.tsx` — Main page with tabs
- `StudioHeader.tsx` — Back button, platform indicator, tabs
- `CanvasView.tsx` — Design canvas with tools
- `GenerativeSidebar.tsx` — AI generation controls
- `MediaGallery.tsx` — User's uploaded images
- `FormatSelector.tsx` — Platform format dropdown
- `ZoomControls.tsx` — Canvas zoom controls

## Sample Data

- `data.json` — Sample studio state, layers, and AI generation data
- `types.ts` — TypeScript interfaces
