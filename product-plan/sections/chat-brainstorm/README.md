# Chat & Brainstorm Section

Conversational AI interface for design ideation with NANO AI assistant.

## Components

- `ChatInterface.tsx` — Main chat container
- `ChatHeader.tsx` — Mode tabs and conversation controls
- `ChatMessage.tsx` — User/AI message rendering
- `ChatInput.tsx` — Message composition with attachments
- `ConversationHistory.tsx` — Past conversations sidebar

- `data.json` — Sample conversations and modes
