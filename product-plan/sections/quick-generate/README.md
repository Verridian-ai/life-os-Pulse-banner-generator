# Quick Generate Wizard Section

## Components

- `QuickGenerateWizard.tsx` — Main wizard container
- `StepIndicator.tsx` — Progress dots
- `StartingPointStep.tsx` — Template or fresh start
- `DescriptionStep.tsx` — Prompt input with enhancement
- `FormatStep.tsx` — Platform and format selection
- `ABTestResults.tsx` — Multiple variant comparison
- `VariantCard.tsx` — Individual design option
