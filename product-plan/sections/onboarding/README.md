# Onboarding Section

First-time user experience for Signal.

## Components

- `OnboardingPage.tsx` — Main page with step management
- `WelcomeStep.tsx` — Logo, tagline, CTA
- `ProfileStep.tsx` — Name and avatar setup
- `PlatformsStep.tsx` — Platform selection grid
- `ApiStep.tsx` — API key configuration
- `FirstDesignStep.tsx` — Template or scratch choice
- `ProgressIndicator.tsx` — Step dots

## Sample Data

- `data.json` — Sample onboarding steps and user preferences
- `types.ts` — TypeScript interfaces
