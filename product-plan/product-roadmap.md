# Product Roadmap

## Sections

### 1. Onboarding
Landing page, signup/login flow, OAuth (Google/GitHub), and payment/subscription management. Includes idle timeout handling and session management.

### 2. Dashboard
Platform hub showing 6 social platform cards (LinkedIn, YouTube, Instagram, Facebook, TikTok, X), recent designs with search/filter, templates access, and brand kit panel. Entry point for all studios.

### 3. Platform Studio
AI-powered design canvas for each social platform:
- Fabric.js canvas with 8+ format presets per platform
- AI image generation (Gemini 3 Pro, OpenRouter, Replicate)
- Image tools (upscaling, background removal, enhancement, restoration)
- Voice Agent with 17 natural language commands
- Safe zones with profile picture overlay
- Zoom controls, layers panel, undo/redo
- Export in multiple formats

### 4. Chat & Brainstorm
Conversational AI interface for design ideation:
- Multi-turn conversations with NANO AI
- Image attachment support
- Conversation history persistence
- Mode switching (design, search, voice)
- Chat archiving and settings

### 5. LinkedIn Content Studio
Specialized LinkedIn content creation:
- Copywriting assistance panel
- Viral score calculation
- LinkedIn image generator with post preview
- Content optimization suggestions
- Direct publishing to LinkedIn

### 6. Quick Generate Wizard
Streamlined design creation flow:
- Step-by-step onboarding wizard
- Template selection
- Prompt refinement with AI enhancement
- Quick canvas generation
- A/B variant testing (3-5 alternatives)

### 7. Templates
Pre-designed professional templates organized by platform, industry, and use case. Searchable and filterable template library for quick-start design.

### 8. Brand Kit
Brand consistency engine:
- Extract colors and fonts from reference images
- Store multiple brand profiles
- Set active brand for automatic enforcement
- Color palettes, typography, and style guidelines

### 9. Projects
Design library with folders, drafts, published work, and asset organization. (Coming Q1 2026)

### 10. Settings
User preferences and configuration:
- API key management (OpenAI, Replicate, etc.)
- Theme selection (light/dark)
- Keyboard shortcuts customization
- Notification preferences
- Account settings

### 11. Admin Dashboard
Administrative controls (admin users only):
- **Overview** — Usage stats, active users, generation metrics
- **Users** — User management, search, activity details
- **Agents** — AI agent configuration and monitoring
- **Observability** — Logging, error tracking, system health
- **Finance** — Usage billing, cost tracking per user/model

8. Change format/dimensions

10. Duplicate element
11. Delete element

13. Change colors
14. Apply brand
15. Export design
16. Navigate to section
17. Open settings

### Tool Chain Builder
Multi-step workflow automation:
- Chain multiple AI operations
- Sequential execution with progress
- Preset workflows for common tasks

### A/B Testing
Design variant generation:
- Generate 3-5 alternatives automatically
- Compare side-by-side
- Track performance metrics
