## Recommendations

### For Web Use
- **Prefer SVG format** for scalability and smaller file sizes
- Use PNG for raster-based designs or when SVG support is limited

### For Print
- **Use vector formats** (SVG, or request EPS/AI from official sources)
- Ensure minimum size requirements per brand guidelines

### For Presentations
- PNG format works well for most presentation software
- Maintain aspect ratios when resizing

### For Development
- SVG can be easily embedded in HTML/CSS
- Consider using official CDN links when available for better performance
