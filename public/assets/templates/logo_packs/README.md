## File Formats

Logos are available in various formats including:
- SVG (Scalable Vector Graphics) - Recommended for web and scalable applications
- PNG (Portable Network Graphics) - Raster format with transparency
- ZIP archives - Complete brand asset packages

## Usage Guidelines

Each company has specific brand guidelines for logo usage. Please refer to the `source_url.txt` file in each company's folder for links to official brand resources and usage guidelines.

## Important Notes
