## 💡 Speaking Tips

✅ **DO:**
- Speak clearly and naturally
- Wait for "listening..." indicator
- Use complete sentences
- Review previews before applying

❌ **DON'T:**
- Rush or speak too quietly
- Interrupt the AI response
- Use command names (just describe what you want)
- Skip disconnecting when done

## ⚙️ Preview Mode Explained

**5 Commands with Preview:**
- generate_background
- magic_edit
- upscale_image
- restore_image
- enhance_face

**How it works:**
1. Command executes → Image generated
2. Preview appears in sidebar
3. **Review** the result
4. Click **"Apply"** (keep) or **"Reject"** (discard)
5. No cost if you reject!

**12 Commands without Preview:**
- Execute immediately
- Use **"Undo"** to revert
- All are FREE operations

## 🎓 Pro Tips

1. **Chain Commands:** "Generate a blue background, then add my name in white text"
2. **Be Specific:** "Add text at x:400, y:200" vs. "Add text somewhere"
3. **Use Quality Levels:** Start with 1K/2K, finalize with 4K
4. **Preview Everything:** Set preview mode on for expensive operations
5. **Session Persistence:** Voice stays connected when switching tabs
6. **Error Recovery:** Say "Undo that" to quickly fix mistakes
