## Installation Methods

### For Claude.ai (Web)
```
Settings > Capabilities > Enable and upload custom skills
```
Built-in skills from Anthropic partners:
- Canva
- Notion
- Figma
- Atlassian

---

### For Claude Code CLI

**Method 1: Plugin Marketplace**
```bash
/plugin marketplace add anthropics/skills
/plugin install [skill-name]@[source]
```

**Method 2: Claude Plugins Registry**
```bash
npx claude-plugins install [skill-name]
```

**Method 3: Direct Installation**
```bash
git clone https://github.com/[author]/[skill-repo].git
```

**Method 4: AI Agent Skills**
```bash
npx ai-agent-skills install [author/repo]
```

---

### For Claude API
- Use Anthropic's pre-built skills
- Upload custom skills via `/v1/skills` endpoint
- See: https://platform.claude.com/docs/en/agents-and-tools/agent-skills

## Security Considerations

⚠️ **Important**: Skills can execute arbitrary code in Claude's environment.

- Always review code before installation
- Only use trusted sources
- Community skills are not formally audited by Anthropic
- Read the terms of service for marketplace platforms

**Anthropic's Assessment**: "We do not audit, endorse, or guarantee the security or correctness of listed projects"
